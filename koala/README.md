# הקואלה של הגן

מצגת אינטראקטיבית לילדי גן על הקואלה: עובדות, איורים, כדור הארץ שמסתובב ונעצר באוסטרליה, ומשחקים קצרים (קואלה או דוב, מחבואים ביער, הפסקת תנועה, תפסו את העלים, מלבישים את הקואלה ומשחק זיכרון).

לפתיחה: `koala/index.html` בדפדפן, או דרך GitHub Pages בכתובת `/koala/`.
ניווט: כפתורי "הבא" ו"הקודם", או מקשי החיצים במקלדת.
